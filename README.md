# موقع مدار — دليل النشر

هذا المجلد يحتوي موقعك جاهزاً بالكامل. كل ما تحتاجه هو رفعه على استضافة مجانية
لتحصل على رابط يفتحه أي طالب من أي جهاز (آيفون أو أندرويد أو كمبيوتر) عبر المتصفح
مباشرة — بدون تحميل أي تطبيق.

## أسهل طريقة (بدون أي أوامر برمجية)

### الخيار 1: Netlify Drop
1. افتح [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد `madar-website` كاملاً وأفلته في الصفحة
3. خلال ثوانٍ يعطيك رابطاً مباشراً مثل: `madar-xyz123.netlify.app`
4. هذا الرابط شارِكه مع الطلاب مباشرة — يعمل فوراً

### الخيار 2: GitHub Pages (رابط دائم باسمك)
1. أنشئ حساباً مجانياً على [github.com](https://github.com)
2. أنشئ مستودعاً (Repository) جديداً، وارفع ملفات هذا المجلد إليه
3. من إعدادات المستودع Settings → Pages، فعّل GitHub Pages من الفرع الرئيسي
4. سيصبح موقعك متاحاً على رابط مثل: `username.github.io/madar`

## ملاحظات مهمة

- لا تحتاج أي حساب مطوّر، ولا رسوم اشتراك، ولا Mac — هذا الفرق الجوهري
  عن مسار التطبيق عبر متاجر التطبيقات.
- إذا فتح الطالب الرابط من هاتفه ثم اختار "إضافة إلى الشاشة الرئيسية" من
  قائمة المتصفح، ستظهر أيقونة الموقع على شاشته الرئيسية وتُفتح بملء الشاشة
  مثل تطبيق حقيقي تقريباً — دون الحاجة لأي متجر.
- المحتوى حالياً مخزّن مؤقتاً داخل كود الصفحة نفسها. أي تعديل أو إضافة يحتاجها
  الموقع لاحقاً (تخزين دائم يحفظ ما يضيفه الطلاب، رفع ملفات PDF حقيقية) يمكن
  إضافته لاحقاً بربط الموقع بقاعدة بيانات بسيطة — أخبرني إذا وصلت لهذه المرحلة.
